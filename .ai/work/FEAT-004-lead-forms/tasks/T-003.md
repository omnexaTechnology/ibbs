When home lands, render `<CallForm whatsappHref={whatsappHref(settings, locale)} />` in its quick-call block (see `src/components/forms/call-form.tsx`) and add it to `e2e/lead-forms.spec.ts`.

Tests: `e2e/lead-forms.spec.ts` (EN+AR, contact and project: `method="post"`, mocked `/api/leads` 200 shows success, payload formType/locale/pageUrl); contact unit test and `e2e/contact.spec.ts` updated.

Rate limit (dashboard step, no in-app limiter). Vercel Firewall custom rule:
- Name: Rate limit lead submissions
- If: Request Path equals `/api/leads` AND Method equals `POST`
- Rate limit: 5 requests per 1 minute, keyed by IP address
- Then: Deny (response 429)
- Publish the rule (Project > Firewall > Configure > Custom rules). Not verified here (needs dashboard access); the AC box stays unchecked until the user adds it (USER-ACTIONS).
