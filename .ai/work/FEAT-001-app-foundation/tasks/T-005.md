## Result
Commit: c0590db.

Done:
- src/components/layout/page-transition.tsx: PageTransitionProvider + usePageTransition(). navigate(href) runs the design sequence: curtains close, router.push at 1150ms, wait until the URL has committed (polls location every 40ms, 5s safety timeout), scroll to top behind the curtains, 110ms later open, overlay removed 1140ms after that (~2.4s total for a fast navigation). One transition at a time; navigating to the current URL is not intercepted. Overlay markup/CSS ported from the design (src/styles/page-transition.css), label = target page name (override with Link prop transitionLabel, for FEAT-003 project titles), plus an sr-only role=status announcement.
- Transition-aware Link: src/components/layout/transition-link.tsx, exported as Link from src/i18n/navigation.ts (so all shell links transition); modified clicks, target/download, hash/external/mailto/tel links and locale-switch links fall back to normal navigation. Plain (non-transition) wrappers moved to src/i18n/navigation-base.ts and exported as PlainLink; LangSwitch uses PlainLink. Browser back/forward are not intercepted, so they work natively and without a transition.
- src/hooks/use-reduced-motion.ts (useSyncExternalStore on prefers-reduced-motion): with reduced motion navigate() just calls router.push, no overlay is rendered (CSS also hides .tr), the cursor is not enabled, and a global reduced-motion rule in globals.css shortens all CSS animations/transitions and disables smooth scroll (BR-002).
- src/components/layout/custom-cursor.tsx + src/styles/custom-cursor.css: ported setupCur (trailing ring, 'go' arrow over a/button/select/label/tab, 'view' eye over img/canvas/[data-cursor=view], press state). Enabled only when (pointer: fine) and not reduced motion; adds html.has-cur which hides the native cursor.
- Mounted in src/app/[locale]/layout.tsx.
Not done / differences: the language switch keeps a plain navigation (design used a separate 280ms content fade for language toggles, not the curtain transition). Auto-advancing animations do not exist yet (FEAT-003 must honour useReducedMotion).

Tests: unit page-transition.test.tsx (timing with fake timers, scroll to top, commit wait + timeout, reduced motion, same-URL, double navigation) and transition-link.test.tsx (plain/modified/external/locale clicks); e2e/motion.spec.ts (real close->swap->open on /en -> /en/about incl. URL unchanged for 500ms, scrollY=0 after, overlay removed; Arabic label; back/forward without transition; ctrl-click; cursor active for mouse and 'go' state over link; coarse pointer = no cursor; AC-004 with reducedMotion=reduce: navigates <1s, overlay never rendered, no has-cur).
Validation: tsc clean; lint clean; npm test = 8 files / 60 tests passed; build success; test:e2e = 21 passed (chromium).
