## Result
Done 2026-10-27. Files: `src/app/[locale]/projects/page.tsx`, `src/components/sections/projects/{projects-floor,projects-explorer}.tsx`, `src/three/scenes/projects-floor.ts`. Tests: `projects.test.tsx`, `scenes/projects-floor.test.ts`, `e2e/projects.spec.ts`.
- 3D floor ported from `initPj3d` (same layout, lights via `legacyIntensity`, drag with inertia, Left/Right arrows, Home resets; canvas is focusable). Loaded through `SceneRoot` from a small client wrapper, so Three stays in the lazy chunk (B1-01 guard unchanged and green). The still fallback is the isometric line drawing.
- B1-11: the design renderer for this scene is ACES / exposure 1.0 (`IBSS3D.renderer` defaults), the same as `SceneRoot` defaults, so no `toneMapping` override is needed.
- Reduced motion: no inertia or smoothing; the view turns only on input, and one still frame is redrawn.
- List: category tabs with counts (all + 6), project-type and city selects, live search (EN+AR title, sector, city), 8 per page (2 rows), page buttons with gaps. `?category=` pre-selects the tab (read with `useSearchParams` inside Suspense, so the page stays static) and clicking a tab updates the URL with `replaceState`.
- Gaps vs design: no hover "peek" preview, no staggered grid animation, no mode switch box on the hero, card styling approximated (no hover reveal of badges/button), the type select lists only scopes that exist in the data. Selects are native.
- AC-002 after a Studio edit not exercised (needs a Studio edit; the page is static and uses the same revalidation tags as the project page).
