# IBSS Innovations Furniture — Project Context

> Generated by `bootstrap` on 2026-10-26. No application code exists yet; this file is grounded in the design export in `design-reference/` and in what the user has decided so far.

## Purpose

Public marketing website for **IBSS Innovations Furniture** (Saudi Arabia): a company that plans, supplies and installs furniture for offices, company headquarters, medical centres, schools, universities, mosques and government bodies. Visitors browse projects and send a project request. A Sanity Studio dashboard lets the client edit the content.

Actors: Public visitor (EN or AR) · Client content editor (Sanity Studio) · Omnexa developer/admin.

## What the design contains (evidence)

**Views:** home, about, projects (list), project (detail), contact, privacy, terms. Navigation via `go(view)` with a full-screen page transition.

**Global:** EN/AR with RTL (`lang` state, ~120 UI string keys per language in `T`), light/dark theme, custom cursor, header with scroll state + mobile menu, footer (main links, project categories, legal links), floating WhatsApp button, reduced-motion handling.

**Content data now hard-coded in the design:**
- Projects `PR` (6): id/slug, category, cover, gallery (4), area m², duration days, year, city, title, challenge, solution, image hotspots, scope items, client (placeholder).
- Project categories `CATS` (6): hq, exec, health, mosque, school, uni (+ label, icon).
- Scope library `scopeLib` (7): executive desks, chairs, meeting tables, workstations, reception, storage, lounge.
- Hero slides `SL` (4): image, alt, kicker, two headline lines, 3 hotspots each.
- Process stages `stepsData` (4): tag, title, short text, callouts.
- Materials `matsData` (6): name, description, uses, image, swatch.
- Testimonials (sample copy), FAQs, sectors list, partner marks (placeholders), client logos (placeholder).
- Stats (props): projects 120, area 85k m², clients 60, years 10 — marked "placeholders pending confirmation".
- About: who we are, vision / mission / goal, 6 strengths.
- Site config: `formEndpoint` (empty = demo mode), social URLs (LinkedIn, Instagram, X, Snapchat, TikTok), phones, emails, website, working hours, WhatsApp number — all placeholders (`+966500000000`, `example.com`).

**Interactive / 3D (Three.js r15x, procedural models + `assets/cd80e49e…json` model data):**
- Home hero 3D scene with stages (`setupScene`, `applyStage`), CTA 3D, lamp scene.
- Office walk-through mode (`setupWalk`: scroll to walk, markers, object picking, tooltips).
- About page: reception + boardroom assembled step by step (`initAb3d`).
- Projects page: open-plan floor turned by drag/keys (`initPj3d`).
- GSAP 3.12.5 + ScrollTrigger (from cdnjs), counters, carousels, accordion, lightbox gallery, project peek preview, projects grid with search / city filter / pagination.

**Forms:** contact form (`f-*`) and project form (`pf-*`), fields name, company, email, phone, type (space type), area, message; plus a "request a call" quick form. Submits `POST formEndpoint` when set.
